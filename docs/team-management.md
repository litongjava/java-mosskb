# 团队与用户管理

- 内置 admin 为 SUPER_ADMIN，通过用户管理创建 ADMIN；每个 ADMIN 的账号 ID 是独立团队 ID。
- ADMIN 通过用户管理创建 USER，成员自动继承管理员的团队。请求不能指定角色或团队。
- 团队内共享应用、知识库、模型和函数库。资源 user_id 保存团队管理员 ID；个人资料、密码和用户管理仍使用真实账号 ID。
- 超级管理员管理全部账号；资源界面显示其自身团队资源。团队管理员只能管理自己团队的普通用户。
- 停用或删除团队管理员后，其成员不能继续访问团队资源；资源保留，不级联删除。
- 原团队成员页面尚无完整后端实现，入口已合并到用户管理。
- 邮箱设置按团队保存，密码回显为掩码。原有未实现的测试邮件按钮已移除。认证、主题等原有占位功能不在本次实现范围。
- 模型供应商目录是平台共享目录，仅超级管理员可修改；模型凭据和模型实例按团队隔离。

## 升级

已有数据库先备份，再执行 `db/team-upgrade.sql`，然后发布后端和前端并重新登录。升级只将已有账号的空团队归属设为其自身 ID，保留原资源归属，不自动合并老账号。新安装执行 `db/init.sql`。

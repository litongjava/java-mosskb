# 后台继续导入

上传文档进入分段页后，文件上传成功即可点击“后台继续导入”。系统复用已上传的解析任务，解析结束后自动生成向量并保存文档。关闭页面不影响服务器处理，文档列表展示任务状态和失败原因。

后台导入使用服务器解析结果，不包含预览中的手工编辑。重复提交同一任务不会重复执行入库，任务只能提交到自己团队的知识库。当前任务恢复逻辑适用于单实例部署：重启时已解析的排队任务继续执行，解析中或入库中被中断的任务标记失败，需重新上传。

已有数据库部署前执行 `db/background-import-upgrade.sql`；新安装执行 `db/init.sql`。应先升级数据库，再发布后端和前端。

验证：前后端构建通过；8 项任务回归测试通过，覆盖状态流转、重复提交、失败记录与跨团队拒绝。回归测试中的入库调用使用替身，不代表远程 OCR 或向量服务端到端验收。
